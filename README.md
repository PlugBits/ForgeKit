# Simple Quote Tools

GitHub Pagesで配布できる、製造業向けのシンプルな見積補助PWAです。

## 機能

- 見積: 溶接、マシニング、旋盤、プレス加工
- 重量計算: 板材、丸棒、角材、六角材、丸パイプ、角パイプ
- 単位換算: 長さ、重量、圧力、温度
- 設定: 時間単価、材質密度

## GitHub Pages

1. このフォルダの中身をGitHubリポジトリにアップロード
2. Settings → Pages
3. Branch: main / root を選択
4. 表示されたURLを開く

複雑な工程別積み上げではなく、すばやく概算するためのツールです。
